7.11. mpdecimal-4.0.1

mpdecimal パッケージは、任意精度 10 進浮動小数点演算にあたって的確な丸めを実現する、高速な C/C++ ライブラリを提供します。

概算ビルド時間: 0.1 SBU 以下
必要ディスク容量: 3.3 MB

7.11.1. mpdecimal のインストール

mpdecimal をコンパイルするための準備をします。 

./configure --prefix=/usr    \
            --disable-static \
            --docdir=/usr/share/doc/mpdecimal-4.0.1

パッケージをコンパイルします。 

make

パッケージをインストールします。 

make install

本パッケージの詳細は 「mpdecimal の構成」を参照してください。
